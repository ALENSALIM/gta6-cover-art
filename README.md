Vice Cover Studio — turn any photo and a caption into GTA-style cover art. Multi-panel cover grid (large hero + smaller panels), bold lettering, Vice City sunset and neon grades, and PNG export in square 1080×1080, portrait 1080×1350 and story 1080×1920. Runs fully offline in a desktop browser from static files; photos never leave the machine.

## Run it

```sh
node serve.ts
# open http://localhost:8080 in a desktop browser
```
